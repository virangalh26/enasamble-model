# Ensemble Model — AML Assignment 2

Ensemble learning on a real Sri Lankan dataset, with SHAP/LIME explainability, a Streamlit inference app and an MLOps deployment pipeline.

## Layout

- `data/` — raw and processed data (not committed)
- `notebooks/` — EDA, modelling, explainability
- `src/` — reusable training and preprocessing code
- `app/` — Streamlit inference app
- `models/` — saved model pipelines
- `reports/` — figures and write-up
- `tests/` — tests run in CI
